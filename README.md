# Demos

A collection of demo projects.

## Projects

### [TappityTap](tappitytap/)

A multiplayer typing race game built with [Durable Streams](https://github.com/durable-streams/durable-streams) and [TanStack DB](https://tanstack.com/db). Players race to type literary passages as fast as possible, competing head-to-head with live progress bars, WPM tracking, and instant results.

Built with [Kyle's Playbook](https://github.com/KyleAMathews/kpb) and [Claude Code](https://claude.com/claude-code).
